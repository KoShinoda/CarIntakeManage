予定表ディスプレイ 設定マニュアル
==================================

PC を立ち上げたとき、予定表ウェブアプリを指定のモニターに全画面で表示する。
普段は「修理入庫予定表」、まれに「一般修理管理表」に切り替える。


■ 用意するもの
----------------------------------
・C:\display フォルダに次の5ファイル（すべて同じフォルダに置く）

    01_初回ログイン.bat       … 初回作業 1
    02_起動時に登録.bat       … 初回作業 2
    登録を解除.bat            … 元に戻すときだけ使う
    予定表ディスプレイ.ps1    … 本体（直接は触らない）
    マニュアル.txt            … このファイル

・Google Chrome（入っていなければ先にインストール）
・会社の Google アカウント

バッチファイルはダブルクリックで実行する（管理者として実行は不要）。
表示用 PC では、普段そのモニターを使うユーザーでサインインして作業する。


■ 初回作業
----------------------------------
1. 01_初回ログイン.bat（最初の1回だけ）
   → 通常の Chrome ウィンドウが開く
   → 会社のアカウントでログインし、アクセスを許可する
   → 修理入庫予定表が出たらウィンドウを閉じる

2. 02_起動時に登録.bat
   → スタートアップに「予定表ディスプレイ」ができる
   → デスクトップに「修理入庫予定表を表示」「一般修理管理表を表示」ができる
   → 画面にモニター一覧が出る。「← 表示先」が付いたモニターに表示される
   → 30秒たつか、何かキーを押すと閉じる

3. デスクトップの「修理入庫予定表を表示」をダブルクリック
   → 縦置きモニターに修理入庫予定表が全画面で出れば OK
   → Alt+F4 で閉じる
   → 普段使いの Chrome が閉じていないことも確認する

4. デスクトップの「一般修理管理表を表示」をダブルクリック
   → 一般修理管理表が全画面で出れば OK
   → Alt+F4 で閉じる

5. PC を再起動する
   → サインイン後、修理入庫予定表が全画面で出れば OK


■ 違うモニターに出る場合
----------------------------------
1. 02_起動時に登録.bat を実行したときのモニター一覧で、表示したいモニターの番号を確認する
2. 02_起動時に登録.bat を右クリック → 編集 でメモ帳を開く
3.     set MONITOR=
   を確認した番号にする（例: set MONITOR=1）。保存する
4. 02_起動時に登録.bat をもう一度ダブルクリックする
   → 一覧で、選んだモニターに「← 表示先」が付いていれば OK
5. デスクトップの「修理入庫予定表を表示」で、正しいモニターに出るか確認する


■ 元に戻す（テストだけのとき）
----------------------------------
登録を解除.bat をダブルクリックする。次の2つが消える。
  ・02 で作ったショートカット3つ（02 をやっていなければ何もしない）
  ・01 でログインした表示専用の Chrome プロファイル（Google のログイン情報）
全画面表示が開いていても、自動で閉じてから消す。
普段使いの Chrome やそのログイン情報には影響しない。

最後に C:\display フォルダを手で削除すれば完全に元どおり。


■ 普段の使い方（表示用 PC）
----------------------------------
・電源を入れてサインインすると、修理入庫予定表が自動で全画面表示される
・一般修理管理表に切り替える: デスクトップの「一般修理管理表を表示」をダブルクリック
・修理入庫予定表に戻す: デスクトップの「修理入庫予定表を表示」をダブルクリック
・全画面を閉じる: Alt+F4
・表はスプレッドシートの内容を30秒ごとに読み直す


■ 注意
----------------------------------
・登録後は C:\display を移動したり、名前を変えたりしない
  （ショートカットがこの場所を覚えている。動かした場合は 02 をやり直す）
・C:\display に .ps1 ファイルは「予定表ディスプレイ.ps1」1つだけ置く
  （バッチファイルは同じフォルダの .ps1 を探して呼び出す）
・登録はサインインしたユーザーごと。別のユーザーで起動すると表示されない
・表示用 PC が自動でスリープやロック画面にならないよう、Windows の電源設定で無効にしておく
・ネットワークがつながるまで最大2分待ってから表示する
・バッチファイルを開くと「Windows によって PC が保護されました」と出た場合は、
  「詳細情報」→「実行」を押す


■ PowerShell で直接実行する場合（参考）
----------------------------------
    cd C:\display
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1 -Setup
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1 -Install
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1 -Install -Monitor 1
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1 -App general
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1 -List
    powershell -ExecutionPolicy Bypass -File .\予定表ディスプレイ.ps1 -Remove
